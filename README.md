# Сайт «Сыроварня Натальи Уско»

Статический сайт сыроварни в Ставрополе: HTML + CSS + чистый JS, без сборки и зависимостей. Тексты — собственный копирайт бизнеса, фото — из архива заведения.

## Страницы

| Файл | Раздел |
| :--- | :--- |
| `index.html` | Главная |
| `about.html` | О сыроварне |
| `cheeses.html` | Каталог сыров |
| `dairy.html` | Молочное, мясное, десерты |
| `frozen.html` | Заморозка и цены (полный прайс) |
| `delivery.html` | Доставка и предзаказ |
| `gifts.html` | Подарки, дегустации, кафе |
| `reviews.html` | Отзывы (2ГИС, 4.9 из 5) |
| `contacts.html` | Контакты и филиалы |

Оформление и логика — в `assets/` (`css/`, `js/`, `img/`, `favicon.svg`).

## Локальный запуск

Открыть `index.html` в браузере, либо:

```bash
python -m http.server 8123
```

## Публикация

Любой статический хостинг (Netlify, Vercel, Cloudflare Pages, обычный shared-хостинг). Бэкенда нет: форма на контактах открывает WhatsApp с готовым текстом заявки.

### GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)` → Save.
Сайт будет доступен на `https://<username>.github.io/syrovarnya-site/`.

После публикации домена рекомендуется обновить `og:image` на главной (сейчас относительный путь) и добавить `sitemap.xml` / `robots.txt`.
